# SimulaEnem

Repositório preparado para publicar o simulado como um site estático pelo GitHub Pages.

## Enviar o HTML único

O arquivo principal precisa se chamar `index.html` e ficar na raiz do repositório. Substitua o `index.html` inicial por seu arquivo completo.

Como o arquivo tem cerca de 28 MB, o envio pelo navegador do GitHub pode falhar devido ao limite de upload. Use o GitHub Desktop ou Git pela linha de comando para adicionar e enviar o arquivo.

## Ativar o GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)` e salve.
4. Aguarde a publicação. O endereço do site aparecerá na mesma seção **Pages**.

O repositório é público, então o conteúdo publicado também ficará acessível publicamente.
